## 8. BUG FOUND — not fixed per §6 (report only)

**`process-definitions-array` demoteLeadingParenthetical false-positive.**
`server/scripts/backfill/spanish/backfill-process-definitions-array.js:223-238`.
`isExclusivelyParenthetical(def)` uses `/^\(.*\)$/`, which only checks the **first and last character** are parens. A substantive gloss that merely *starts* with a parenthetical tag and *ends* with a closing paren — e.g. `planta`'s `"(botany) plant (An organism … such an organism.)"` — is mis-flagged as "exclusively parenthetical", so `demoteLeadingParenthetical` wrongly swaps the real "plant" sense out of the lead slot (planta ended up leading with "plant (factory)").

**Impact:** any head-word whose best gloss has the shape `"(tag) word (explanation)"`.
**Fix suggestion:** require a single balanced wrapper, e.g. `/^\([^()]*\)$/`, or a balanced-paren scan that only treats it as parenthetical-only when the matching close of the *opening* paren is the final char.
**Workaround used this run (planta only):** authored planta's Pass-1 order so the (buggy) demote lands a >20-char gloss in the lead, which triggered the short-gloss synth; I answered that "plant". Final planta lead = **"plant"** (correct). Full order: `plant, floor/level, (botany) plant, plant (factory), sole, sole (bottom of a shoe or boot)` — the "floor/level" sitting at #2 is the one cosmetic compromise from the workaround; the card headline is right.
