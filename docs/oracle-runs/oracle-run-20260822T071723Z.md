## Findings for the user

1. **The §5 validator-overwrite query is field-agnostic and will keep crying wolf.**
   It joins *any* `validations` row for an entry to *any* recent stamp of the script
   being checked, without asking whether that script writes the validated field. For
   `backfill-cluster-definitions` (which writes only `definitionClusters`) every
   validated entry it re-clusters is a guaranteed false hit. Suggested fix: constrain
   the query with `val.field = ANY(<fields this script writes>)`.

2. **`definitionClusters` is not covered by `validatedClause` — arguably a real gap.**
   The clusterer guards only `senseFrequencyScore`
   (`validatedClause(['senseFrequencyScore'], 'dictionaryentries_zh')`). A validator who
   flags `definitions` is flagging the gloss list; the clusterer then re-partitions and
   re-orders exactly those glosses into `definitionClusters`, which is what learners
   actually see. 动心 is a live instance: `definitions` flagged 2026-07-25, clusters
   rewritten 2026-08-22. Worth deciding whether a `definitions` flag should also protect
   the derived clusters.

3. **Two unsharded workers are drawing from the same planner scope.** This round was
   told it was solo/unsharded, but a second worker was concurrently running its own
   apply chain. Its batch was byte-adjacent to mine, and my post-round planner call
   returned `动情,动手,动机,…` — *the same batch that worker was already several passes
   into*. Nothing was corrupted here (per-row writes stayed disjoint and each script is
   `--words=` scoped), but this is precisely the collision §6b describes: with no
   `--shard`, the next round of each worker gets a byte-identical `ORDER BY … LIMIT`
   batch and they race the same rows. **Either shard both workers or run one.**

4. **Corpus-quality observations in this batch** (the recurring theme from rounds
   217–222 continues):
   - **加里 ships two unrelated senses under one headword**, one of which
     (potassium, a dated transliteration of Latin *kalium*) is obsolete — modern Chinese
     is 钾. It is discoverable at difficulty 6.
   - **加时's "play-off" gloss is simply wrong** in English: a play-off is a separate
     fixture, not added time. Flagged for review rather than pruned, since removal is
     supposed to be conservative.
   - **Four of the twelve are proper nouns or narrow technical terms** shipped as
     discoverable vocabulary — 加拉加斯 (Caracas), 加尔文 (Calvin the reformer),
     加特林 (Gatling), 加数 (addend). All scored 1–2 for spoken frequency, which is the
     right signal, but they are still on cards.
   - **Near-duplicate source glosses persist**: 动 lists both "to move" and
     "(of something) to move"; 加重语气 lists "to give emphasis" and "with emphasis";
     加数 lists "addend" and "summand".
