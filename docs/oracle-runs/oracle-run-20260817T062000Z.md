## 9. Findings — things that are wrong or worth fixing

**(a) Unstamped writes force a `--stale` pass on every `--new` batch.**
`backfill-tones`, `backfill-numbered-pinyin` and `backfill-dictionary-breakdown`
write data without writing an `enrichmentLog` stamp when the target column is
already populated. The planner then reports the step as pending forever, and
`promote-discoverable.js` refuses the row. Every batch needed an explicit
`--stale` pass on those three before promotion. **Fix**: stamp unconditionally on
a no-change row, the way the other scripts do.

**(b) gsa mis-splits are being baked into stored example sentences.** Observed
this run:

| Sentence | Wrong split | Should be |
|---|---|---|
| 比较好认 | 比 / 较好 | 比较 / 好认 |
| 讲得很清楚 | … / 得很 / … | 得 / 很 |
| 意思 | 同意 / 思 | 意思 |
| 医生摇摇头 | 摇 / 摇头 | 摇摇 / 头 |
| 电梯按钮上都印着点字 | … / **上都** / … | 上 / 都 |

Segmentation is fixed by the time the per-segment labelling prompt runs, so the
labeller is forced to describe a segment that isn't a word — I had to tag the
bogus `上都` as an adverb. That wrong segment is now **stored in
`exampleSentences.segments` on 点字** and will render as a tappable cpcd segment.
This is the most user-visible defect found. **Fix**: either let the labelling
step reject a segmentation and re-segment, or add these to the gsa's
lexicon/tie-break rules.

**(c) es `backfill-process-definitions-array` churns unchanged rows** — it
rewrites and re-stamps rows whose definition array it did not actually change.

**(d) es `backfill-example-sentences`' gate is emptiness-only** — it has no
version-staleness check, so a prompt revision will never re-trigger it.

**(e) `vernacularScore` does not exist on `dictionaryentries_es`**, but the
`/oracle-backfill` skill's §4 es target-selection SQL selects on it. That query
errors as written; drop the column from it.

**(f) Batch-1 content notes** — 字面 glossed "typeface" is not natural modern
Mandarin (字体 is); 定音 is only really idiomatic inside 一锤定音.

**(g) 头文字 is Japanese-derived and barely used in Mandarin** (首字母 is
standard). Its sentences are inherently strained. Shipped with a note rather than
dropped, but it is a candidate for withdrawal.

## 10. Uncertainty disclosure

Inherent to oracle mode and not a defect: **I authored the answers and also
answered the reviewer/critic links that judge them.** Where a chained prompt
asked a junior's proposal to be confirmed, the confirmation is mine over my own
work. The pipeline's mechanical validators (schema, length ceilings, POS
coverage, sentence counts) are genuinely independent and did reject work — see
the 中体西用 length rejection and the four sentence rewrites above — but the
*taste* judgements have no second reader. The 13 cluster-review flags in §6 are
the places I am least confident and most want a human eye.
