## Findings

1. **Deterministic steps under-report against the promotion bar.** `backfill-tones`,
   `backfill-numbered-pinyin` and `backfill-dictionary-breakdown` gate on the column being
   NULL rather than on the enrichment stamp, so already-populated-but-unstamped rows say
   "0 needing backfill" while `promote-discoverable.js` blocks them. `--stale` is the
   workaround; recurring since Round 523.
2. **Re-processing steps.** `process-definitions-array` and `cluster-definitions` re-derive
   on every `--words` run and converge only when the authored answer reproduces the stored
   value. Costs apply cycles on every round.
3. **Example-sentence chain is deep.** 7 export/apply cycles for 12 words. A single rejected
   sentence restarts the review + segment-labelling sub-chain for that sentence.
4. **GSA mis-segmentation reaches the labelling prompt.** `用简单的话解释` was segmented
   `简单 / 的话 / 解释`, merging 的 + 话 into the conditional marker 的话. The labelling prompt
   forbids re-splitting, so the wrong segment was labelled as given.
5. **Non-exemplifiable senses.** 人鱼's "sirenian"/"giant salamander" senses are not usable in
   standalone modern Mandarin (娃娃鱼 is the live term); 面世's "to take shape" is a dubious
   cedict sense and its sentence had to be re-stamped to "to be released to the public".
6. **Short-gloss append defect** on 不自量力 (redundant "to overreach" lead gloss, pruned by
   the critic).
