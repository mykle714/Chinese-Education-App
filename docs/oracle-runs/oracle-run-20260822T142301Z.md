## Findings (recorded, not acted on — §6 says keep going)

1. ⭐ **Unmarked heteronym inside one row.** 给's flat array carries gei3 and ji3 senses
   with no reading marker on either. Cluster-rule 2 makes reading a hard boundary, but
   the boundary is recoverable only from outside knowledge. This is a live instance of
   the exact hazard the prompt's own 会/kuai4 worked example was written to catch, and
   nothing in the data flags it. A detector is cheap: cross-check headwords against a
   multi-reading list (给 会 长 行 得 差 重 …) and flag rows whose glosses span readings.
2. ⭐ **All-parenthetical cluster (new class).** 给's third cluster consists entirely of
   exclusively-parenthetical glosses. Both Stage B prompts state "never place an
   exclusively-parenthetical gloss first" — **unsatisfiable** for this cluster. The rule
   is written per-word but applied per-cluster, and no validator enforces it, so the
   card will lead with a bare parenthetical. Fix: relax the rule for wholly-parenthetical
   clusters, or have the clusterer refuse to emit one.
3. **Same sense, inconsistently tagged across rows.** 经 has `warp (textile)`; 经线 has
   bare, opaque `warp`. Related to the r425 short-then-long opacity class.
4. **Head-gloss inheritance, three rows in one batch.** 经's `scripture` cluster is
   byte-identical to 经文's entire gloss set and overlaps 经书's.
5. **Bound-form marking still absent** on a second high-frequency stem (经, after 节 in
   r423): nearly every 经 sense is bound in modern speech and nothing records it.
