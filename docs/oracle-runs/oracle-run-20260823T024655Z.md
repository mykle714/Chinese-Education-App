## 5. Findings

1. **`backfill-tones` / `backfill-numbered-pinyin` need `--stale` again.** Both reported
   "0 entries needing backfill" while the planner listed rows: the values are present but
   the version stamp is missing, so the scripts' own `doneGate` sees them as done while the
   planner (stamp-driven) sees them as pending. Recurrence of a round-527 finding; the two
   disagree about what "done" means for value-present/unstamped rows.
2. **`乐` has no "music" sense candidate.** In `backfill-breakdown-senses`, 乐's candidate
   list is only `"happy / joyful"` / `"to laugh"` — no yuè "music" sense — so 国乐 and
   木管乐器 had to be tagged "happy / joyful" with a `reviewNotes` protest. The per-character
   sense inventory for 乐 is missing its second reading.
3. **gsa mis-segmentation:** 认准的 was split as 认 / 准的 in one 鱼头 sentence. The labelling
   prompt takes the segmentation as FIXED, so the only option was to label a segment that is
   not a word (tagged `particle`). Flagged rather than worked around.
4. **Near-duplicate glosses survive the short-gloss step.** 黄鱼 → `["yellow croaker",
   "yellow croaker (fish)"]`, 黄花鱼 similarly (`yellow croaker; yellow croaker (fish);
   corvina`). The generated gloss duplicates an existing definition, so the card shows two
   near-identical lines. Kept contract-faithful; worth a dedupe in the definitions step.
5. **Self-review caught 3 of my own long-definition drafts** — 作乐 (`gratuitous_chinese`:
   cited 寻欢作乐, which merely contains the headword), 可口可乐 (`restates_gloss`),
   国乐 (`uses_pinyin`: romanized erhu/pipa/dizi). Re-authored; the judge stage then chose
   the corrected option in all three.
6. **Low-confidence content, disclosed:** 鱼头's figurative "upright / unwilling to compromise"
   sense. I initially declined to write a sentence for it (doubting its currency); the pipeline
   detected the uncovered sense and issued a dedicated prompt, so
   他是出了名的鱼头，认准的事谁劝都没用。was authored. Treat as the weakest sentence in the batch.
7. **Oracle self-review tension** (standing disclosure): the same answerer authors the content
   and then answers the critic/judge/native-review prompts that grade it. The validators are
   unmodified, but the reviewer is not independent.
