## Findings

### 1. `--stale` still required for tones / numbered-pinyin (5th recurrence)
The planner listed both scripts as having work, but each reported "0 needing" until re-run
with `--stale` (tones 1 row, numbered-pinyin 4). Values are present; the version stamp is
missing. Same defect as rounds 527–530. It costs a wasted export pass every round and it is
now consistent enough to be worth fixing rather than working around.

### 2. The `--new` frontier is now majority unauthorable content
**19 of the top 25** planner candidates were explicit sexual vocabulary or ethnic slurs
(法克, 马上风, 工口, 马眼, 阿三, 小日本, 口交, 性交, 手交, 台巴子, 黄书, 情色, 色情, 老黑,
色情业, 日人民报, 基情, 尼格罗, 木子美). Root cause: `CHAR_FREQ_CTE` ranks purely by character
commonness with **no register or offensiveness filter**, so vulgar words built from very common
characters float to the top exactly as clean common vocabulary drains. Handled per skill §6
(drop, note, continue) by pulling `--limit=70` and taking 12 authorable words in planner order.
This is now the dominant cost of a round and the ratio is getting worse each round — the
curation CTE needs a register filter, or the run needs a persistent drop-list so the same
headwords are not re-surfaced and re-rejected every round.

### 3. The 乐 candidate-sense gap recurred (rounds 528, 530, 531)
`backfill-breakdown-senses` offers 乐 only `"happy / joyful"` and `"to laugh"` — the yuè
"music" reading is absent from the 乐 character entry. Three words in this batch (出神音乐,
音乐家, 音乐会) had to be tagged with a knowingly wrong sense under protest, each carrying a
reviewNote. The damage now compounds downstream: because the breakdown shows 乐 = "happy",
`backfill-breakdown-elaboration` judged all three **not** straightforward, so each burned its
one-sentence elaboration correcting the gloss ("音乐 'music' reads 乐 as yuè, not 'happy'")
instead of explaining the compound. Fixing the 乐 character entry would retroactively improve
every 音乐-family word already shipped.

### 4. gsa mis-splits in example-sentence segmentation
有意见 → 有意 + 见; 几百位 → 几 + 百位; 卖完了 → 卖 + 完了.

### 5. Round-71 word-forms defect still live
`wordForms` derives from the FIRST definition only, forcing `{"adjective":"religious"}` for
信教 (a verb) because its lead gloss is adjectival.

### 6. `backfill-classifier` applicability is evaluated too early
Classifier ran mid-manifest and covered 5 rows, but 公信力, 出神音乐 and 黄鱼车 only became
applicable afterwards and blocked promotion (`✗ not ready: backfill-classifier`) until a second
classifier pass. Cheap to re-run, but the manifest order implies one pass should suffice.
