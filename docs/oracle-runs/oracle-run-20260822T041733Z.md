## Findings worth acting on

1. **A v6 clusterer backlog exists on shipped rows.** The refresh scope was pending at
   50/50 on this one step. This round cleared 12; expect many more rounds of the same
   shape before `--discoverable` drains.
2. **A "round of N rows" is not N prompts.** With four chained calls per cluster and
   export capturing only the first, a 12-row clusterer round cost 35 prompts across 7
   apply passes. Worth knowing when sizing a batch against a window boundary.
3. **The skill's §5 verification SQL is written specifically against
   `backfill-example-sentences`.** Retargeted at another script it joins *any*
   approve/flag validation and reports a false violation (it did here, on 一心, before
   being re-scoped). The check should filter on the running step's own
   `validationFields`. Suggest tightening the snippet in `.claude/commands/oracle-backfill.md`.
