## Findings (recorded, not acted on)

1. **Clusters stop being an exact partition of `definitions` once the critic prunes.**
   `REQUIRED_SCRIPTS_ZH`'s comment on `chinese/backfill-cluster-definitions` states checkShape
   "requires the clusters to be an EXACT partition of that array". After this round, 一水儿
   (id=707) has 3 entries in `definitions` and 2 glosses across its clusters — the dropped
   duplicate is still in `definitions`. Reordering done by the ranking pass (一族, 一时) is
   likewise invisible at word level. Either the documented invariant is not actually enforced,
   or `definitions` should be rewritten from the clusters. Worth a decision before the next
   `process-definitions-array` run, which validates against the same array.
2. **Re-clustering does not mark downstream steps stale.** All ten rows kept
   `chinese/backfill-long-definitions` at v15 and were not re-planned, even though clustering
   rewrote the `sense` labels that long-definitions and example-sentences key on. A re-cluster
   that renames a sense silently orphans the downstream text. (Same family as the known
   long-definitions → longdef-citations invalidation noted in the manifest.)
3. **`reviewNotes` surface only on the writing pass.** Notes supplied on the partition call are
   printed only by the apply pass that finally writes the row; earlier passes report
   "Flagged for review: 0". Previously noted in round 72–73; reconfirmed. Not a bug, but it
   means an operator driving the chain manually can lose sight of flags mid-convergence.
4. **Source-data duplicate.** 一水儿's cedict `definitions` carries "of the same type" and
   "(coll.) of the same type". A de-dup sweep over the raw arrays would be cheap.

## Anything uncertain — for a human to double-check

- **一会 vs 一会儿 readings** (see A1.5) — the stored `yi1 hui4` for 一会 is the dictionary
  reading, not what a learner will hear.
- **一族 "clan or family" scored 1.** 一族 in modern speech is essentially the productive
  suffix-like "the X crowd"; the clan sense is close to inert. If a score of 1 hides the cluster
  from a surface, that is probably the right outcome, but it was a judgement call.
- **一气 "forming a gang" is tagged `pos: ["verb"]`** but only ever appears bound
  (串通一气 / 沆瀣一气). If anything downstream conjugates or glosses it as a free verb it will
  read wrong.
- **Self-review caveat.** Oracle mode has the same session author the partition, the ranking,
  the ranking critic, and the frequency score. The critic pass is structurally not independent —
  it confirmed 8 of 9 rankings, which is what you would expect from a reviewer reviewing itself.
  Treat "0 rejected" as evidence the output was *well-formed*, not that it was *right*.
