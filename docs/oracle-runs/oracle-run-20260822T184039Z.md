## Findings (recorded per §6, did not stop the run)

### 1. Export mode is not side-effect-free — HIGHEST PRIORITY

`BACKFILL_ORACLE=export` is documented as "**No DB write, no network**". For three scripts it
demonstrably advanced state:

| script | `enrichmentLog.ranAt` written | which of my passes was running then |
|---|---|---|
| backfill-classifier | 2026-08-22T18:34:36Z (光度, 布尔代数, +8) | **export only** — my classifier *apply* ran at 18:35:49 and touched exactly 1 row (加大力度) |
| backfill-breakdown-senses | 2026-08-22T18:35:38Z (all 11) | **export only** — I never ran this script in apply mode |
| backfill-breakdown-elaboration | 2026-08-22T18:36:07Z (all 11) | **export only** — I never ran this script in apply mode |

The observable consequence: the first export of each script selected 11 / 10 / 11 rows; the
second selected 1 / 0 / 0. Those stamps completed the manifest bar, and **the 11 rows flipped
`discoverable = FALSE → TRUE` between two of my own SQL reads, without me ever running
`promote-discoverable.js --apply`** (its dry run then reported all 11 as "already discoverable",
and `promote-discoverable` has no `enrichmentLog` entry on any row).

The flag itself was **earned** — every manifest step is stamped, difficulty is 1–6 on all 11,
and the global `discoverable_without_level` guard is 0 — and the promotion was presumably done
by `run-lazy-enrichment.js`, which re-derives the same `isComplete` predicate before its
`UPDATE`. So this is not a CLAUDE.md violation. But it means **an oracle export pass can
silently ship words**, which defeats the purpose of a phase that exists to be read-only.

Worth confirming in `server/scripts/backfill/run-log.js` (ORACLE MODE / `OracleExportSignal`)
whether these three scripts stamp outside `handleResponse`, or whether the signal is being
swallowed by a `catch` on their write path.

### 2. `backfill-example-sentences` reports counts that contradict the data

The apply pass printed `Total processed : 2`, `Updated : 0`, `Failed : 2`, yet all 11 rows carry
an `exampleSentences` stamp from that pass (18:31–18:32) — and the stored sentences are neither
mine nor absent. Most likely the rows already had sentences from an earlier enrichment pass and
the script re-stamped without rewriting, but the summary gives no way to tell. **A pass's summary
cannot currently be used to know what it did.**

### 3. The short-gloss stage manufactures the duplication it is blamed for

Logged for 30+ rounds; this round shows the trigger precisely. The stage fires only when the
**lead** gloss exceeds 20 characters — so a ranking decision made earlier *in the same script*
determines whether an extra near-duplicate gloss gets authored at all. Both rows it fired on
this round (三教, 加大力度) had their leads changed by the ranking/critic stages moments before.
三教 now ships three renderings of one name; 加大力度 three renderings of one sense.

### 4. The corpus feeds this stage duplicate glosses it is forbidden to remove

8 of the 9 rows entering `process-definitions-array` arrived as a bare gloss plus a
parenthesized gloss of the **same** sense — "musical third" / "third (musical interval)",
"whole tone" / "whole tone (musical interval)", "the Three Doctrines" / "the Three Doctrines
(Daoism, Confucianism, Buddhism)". The stage's removal rules cover only broken English and
rare-senses-already-covered, so it must keep both, and both stay dd-selectable.

### 5. The `--new` commonness ranker has no word-level frequency signal

The batch was ranked by character commonness (度, 教, 三 are all very common), and produced
rare technical vocabulary: a musical interval, a rare variant of that interval, a whole-tone
interval, instrument graduations, Boolean algebra. **Every row scored conversational frequency
1 or 2 except 加大力度 (3).** Common characters do not imply common words. This is the ordering
that decides which slice of a corpus that will never be fully enriched actually reaches learners,
so it is worth a word-frequency input.

### 6. A `--new` batch is not necessarily a from-scratch batch

All 11 rows already had breakdown, breakdown senses, breakdown elaboration, example sentences,
HSK level, tones, numbered pinyin and difficulty. They were non-discoverable only because
clusters and long definitions were missing. Eight of the fifteen manifest scripts had nothing to
do. Useful for estimating round cost.

手交 台巴子 黄书 情色 色情 老黑 色情业 日人民报 基情 尼格罗 木子美) — at least the fourth
