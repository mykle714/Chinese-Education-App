The 8 passes are the documented chain-convergence behaviour, not failures. The script
makes four call types per row and export can only ever capture the first, so each apply
pass advances one link:

```
Stage A  cluster the glosses            (1 call / row)
Stage B  rank glosses within a cluster  (1 call / cluster)
Stage B' critic reviews that ranking    (1 call / cluster)
Stage C  frequency-score the cluster    (1 call / cluster)
```

A 3-cluster row therefore needs 1 + 3×3 = 10 calls and cannot finish in fewer passes than
its cluster count allows. `了` (3 clusters) set the pass count for the whole batch.

## Findings for a human

1. **了's two `liao3` clusters ship under a `le` headword reading.** Per-cluster `reading`
   is correct, but the entry's primary `numberedPinyin` is `le`, so any surface reading the
   headword reading rather than the cluster reading will mispronounce them. Same defect
   class as 中 / 上头 / 不是 (rounds 177/179) — but unlike those, this one is mechanically
   findable: "entries with a cluster whose reading differs from the row's primary reading."
2. **The ranking prompt contains an unsatisfiable rule.** "An exclusively-parenthetical
   gloss must never rank first" cannot hold when *every* gloss in the sense is parenthetical
   — exactly the situation for grammatical particles. 了, 的, 着, 过 will all hit it. The
   rule needs an explicit escape clause.
3. **`main instigator` on 事主 may be a source error.** It sits beside three victim/party
   senses with no shared core. Not corrected (rule 1 forbids editing glosses); flagged.
4. **Duplicate-gloss pairs, third round running** — 九 ("nine"/"9"), 事主 ("victim"/"victim
   (of a criminal)"), 事工 ("ministry"/"(Christianity) ministry (…)"). A normalize-and-dedupe
   pass over `definitions` (strip trailing parentheticals, compare) would clear a recurring
   class of near-identical card answers.
5. **干净 is missing its resultative sense.** Source has only "clean"/"neat"; the very common
   吃干净 / 忘干净 "completely, entirely" sense is absent. Rule 1 forbids adding a gloss, so
   this is a source-data gap the clusterer cannot fix.
6. **No postposition tag exists in `ALLOWED_POS_TAGS`.** 之中/之外/之后 are postpositions in
   Chinese and were all tagged `preposition` as the closest available. Three rows this round;
   the whole 之X family will hit it.
7. **Convergence cost.** 12 rows took 8 apply passes and 46 authored answers, and each pass
   re-runs the whole batch, redoing completed rows' DB work. An oracle-aware mode that
   answers every pending call for a row before unwinding would cut this to ~1 pass per row.
8. **事工 and 了's literary senses are register-locked** yet ship as ordinary discoverable
   cards — the same observation logged for 主公 / 主日 / 主日学 in round 185. Recurring
   enough to be worth a policy rather than a per-round note.
