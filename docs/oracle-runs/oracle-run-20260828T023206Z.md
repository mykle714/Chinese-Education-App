or partial run) but never stamped in `enrichmentLog`, so each script's own `WHERE
column IS NULL` doneGate found nothing to do and exited without stamping. Re-running
with `--stale` (which ORs in the stamp-based `staleClause()`) closed the gap. Worth
flagging: any deterministic script whose doneGate is a raw-column NULL check rather
than a stamp check can silently under-report "nothing pending" while
`promote-discoverable` still blocks — the fix here was `--stale`, but a longer-term
fix would be making the plain (non-`--stale`) doneGate also honor missing stamps.
