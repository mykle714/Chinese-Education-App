## QA catches (for future oracle-authoring reference)

1. **example-sentences, 有关**: my own authored generator-stage sentence 1
   originally read "这件事与你无关。" ("This matter has nothing to do with you.") —
   using 无关 (the negated antonym) instead of the target word 有关 itself. Caught
   by re-reading the authored batch before segmentation; fixed before anything
   reached the DB. Lesson: re-read generated example sentences for "does this
   sentence actually contain its own target word" before moving to segmentation —
   a fluent near-synonym/antonym substitution is an easy self-authoring mistake.
2. **breakdown-senses, 机关车**: authored 关→"crucial point, pivot" for the
   locomotive word, but that label actually belonged to 机's candidate list, not
   关's. The script's own validator caught the mismatch and silently substituted
   the correct fallback ("to close; to shut; to turn off"); the row still updated
   successfully. Lesson: double-check a sense label is on *that specific
   character's* candidate list before submitting, not just that it sounds
   plausible for the word as a whole.
