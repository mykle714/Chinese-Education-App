## 10. Findings / recommendations (bugs & inefficiencies noted, not fixed)

- **es fresh rows have `partsOfSpeech = NULL`** and rely on the `parts-of-speech`
  backfill to populate it — this **contradicts the comment** in
  `backfill-long-definitions.js` ("For Spanish, partsOfSpeech is set by the importer…").
  The comment is stale; the POS step is required for new es words. Recommend fixing the
  comment.
- **`process-definitions-array` has no per-row doneGate** — it re-ranks every `--words`
  row on every invocation (the oracle sees this as repeated Pass-1/critic prompts until
  the stored order stabilizes). Functionally correct (converges) but wasteful. A
  `staleClause`/stamp-based skip like the other scripts would avoid the re-ranking.
- **Spanish has no `requiredScripts.js` manifest**, so `oracle-plan.js` cannot plan es
  and there is no version-aware staleness / lazy-enrichment for es. An es manifest would
  let the planner drive es rounds the way it drives zh.
- **`backfill-icons` cannot run in oracle mode** (outbound icons8 HTTP). All 268 new es
  words currently have no icon; a separate non-oracle `backfill-icons --lang=es` pass is
  the follow-up.
