## Notable discovery: `backfill-example-sentences.js`'s third chained stage

Previously documented behavior for this script was generator + native-Mandarin
acceptance review (2 stages). This run surfaced a **third stage**: a per-segment
grammatical labeling task (pos/sense/number/tense) keyed to a sentence's **fixed
segmentation**, run once per sentence index. Its chaining is more granular than any
other script seen in this run — each apply pass reveals only the **next unlabeled
sentence index's** prompt per word, not all three at once. Closing this stage out
for the 10-word batch required 3 separate append-and-reapply rounds (index 0, 1,
2) rather than the usual 1. This is worth folding into the skill's or a future
report's documentation of the script, since neither currently mentions it.

Segment-labeling prompt contract (verbatim from the system block): label each
FIXED segment (never re-split/merge/add) with `pos` (12-way tagset, nominally-used
verbs tagged noun), `sense` (only for segments shown with candidate senses — copy
verbatim), `number` (nouns only, from the English translation), `tense` (verbs
only, judged from meaning not just grammatical markers). Model named in script:
`claude-sonnet-4-6` (ignored under oracle mode).
