### Prompt-id pre-computation

The clusterer chains ~12 model calls per row (Stage A split → Stage B pass-1 sort →
Stage B pass-2 critic → Stage C per-cluster frequency), and the export phase can only
ever capture the *first* call in a chain. Rather than run 13 apply rounds, the run used
a throwaway helper (`scripts/backfill/oracle-genids-tmp.mjs`, deleted afterwards) that
imported the **real** prompt builders (`createGlossOrderer`, `createFrequencyScorer`)
and the **real** hash (`oraclePromptId`) behind a stub Anthropic client, and emitted the
promptIds for every downstream call. Fidelity was proven by re-deriving the two ids that
had already been captured live (`fec739bea263ab3b`, `753e423fd6f8772f`) — both matched
exactly. No prompt text was guessed or hand-written; every answer still went through the
untouched validators.

### `backfill-long-definitions` — one self-caught revision

The first generator answer for 上头 opened the "to be addictive / gripping" pair with
*"Something grips you so completely…"*, which echoes the sense label — a rule-6
(`restates_gloss`) violation. Rather than pass it through the validator and approve my
own violation, the generator answer was rewritten to *"Once it takes hold you keep
returning to it without ever deciding to…"* before validation. Both arrays were then
accepted on the first validator pass (`[sonnet ✓] 5/5 pairs, max 149/200` and
`4/4 pairs, max 135/200`); no opus retry was triggered.

## Uncertain / needs a human look

1. **The two heteronym readings above** — the highest-value follow-up in this run.
2. **`partsOfSpeech` is now stale against the clusters on 小子.** The word-level column
   reads `["noun"]`, but cluster 4 is a pronoun. `backfill-parts-of-speech` runs *before*
   clustering in manifest order and nothing reconciles the two afterwards, so a POS the
   clusterer discovers can never reach the word-level column. This is a pipeline gap, not
   a bad answer: either have the clusterer union its cluster POSes back into
   `partsOfSpeech`, or make consumers read POS from the clusters and retire the
   word-level column as a cache. **Not fixed in this run** (out of scope).
3. **`exampleSentences` were generated against the OLD v4 clusters** on both rows and
   still carry the pre-existing sense labels. `backfill-example-sentences` is stamped at
   manifest v6 so the planner does *not* consider it stale — but the cluster set beneath
   it changed (上头 went 4 → 5 clusters, and both words' sense labels/readings moved).
   A cluster rewrite arguably ought to invalidate downstream example sentences the way it
   already invalidates `longDefinitionCitations`. Worth considering a manifest-level
   dependency rule; the sentences themselves were not inspected for drift in this run.
4. **上头 cluster 1 vs 2 boundary** — "to go to one's head" was placed with the alcohol
   sense, but the bare gloss is genuinely ambiguous between the intoxication reading and
   the modern addictive reading. The Stage A.5 merge pass is opt-in and was **not**
   enabled (matching how the rest of the corpus was clustered), so no automatic
   consolidation was attempted.
5. **Self-review tension.** In oracle mode the same session authors and validates every
   answer, so a "first-pass accept" is weaker evidence than an independent review would
   be. The one rule-6 violation found was caught and rewritten before validation rather
   than approved; there may be others that self-review did not catch.
