## Findings (not fixed — recorded per §6)

1. **`backfill-icons` sends the whole lead definition as the icons8 search term.**
   Two rows failed with `icons8 search HTTP 400` because the term was a full sentence:
   `"Zhongshan, prefecture-level city in Guangdong Province 廣東省|广东省[Guang3 dong1 Sheng3]"`
   and `"Dashan, stage name of Canadian Mark Henry Rowswell, actor and well-known TV
   personality in PRC"`. 中山市 and 大山 still have no icon. The fix is to truncate/clean the
   search term (first clause, drop bracketed cedict refs) before the query.
2. **Icon *quality* for abstract words is poor even when the call succeeds.** 不无 → "Not
   grapefruit"; 心头 → "Diamond Heart"; 中学生 → "Middle East". The search term is a literal
   gloss with no notion of concreteness. Worth a concreteness gate or a fallback.
3. **Per-cluster vernacular score swallows `OracleExportSignal`.** The sub-call that scores
   each cluster catches the unwind instead of propagating it, so on a first full pass the
   cluster is written with `vernacularScore: null` and a ⚠ line, rather than the row being
   deferred. Workaround used: re-run the step and answer the captured score prompts. This
   worked everywhere except **`无`**, where the re-run never converges (each apply captures a
   fresh prompt) — **`无` still has 1 cluster with a null `vernacularScore`.**
4. **`process-definitions-array` is not idempotent under the oracle.** A successful write
   changes `definitions`, which changes the row's own prompt hash, so the next apply
   re-prompts an already-complete row (seen on 人头/大头/斯 and 4 batch-3 rows). Harmless but
   it inflates the "Failed/invalid" count and wastes a cycle; the planner is the reliable
   completion check, not the script's own summary.
5. **The gsa mis-segments several sentences**, and the per-segment labelling contract forbids
   re-splitting, so wrong segments had to be labelled as-is: 大家的 → 大 + 家的; 合作对 → 合 +
   作对; 儒家的 → 儒 + 家的; 完成了 → 完 + 成了; 一个人口 → 一个人 + 口; 最好多 → 最 + 好多;
   一共有 → 一 + 共有; 得很 → 得很. Transliterations are split per character
   (斯洛伐克 → 斯/洛/伐/克). These produce visibly odd per-segment glosses on the affected cards.
6. **Duplicate segment strings collapse.** The labelling response is keyed by segment string,
   so a sentence containing the same segment twice (e.g. 大学 and 心理学 both contributing 学)
   gets one entry, not two.

## Things a human should double-check

- **中山** — I ordered "Sun Yat-sen" ahead of the city/district cross-references and flagged it
  `low_confidence`. In mainland text 中山 standing alone most often means the Guangdong city.
- **区 / 学 / 市 bound senses.** "to distinguish" (区), "field of study" (学) and "to trade" (市)
  cannot form natural standalone sentences in modern Mandarin. The top-up pass demanded a
  sentence for each, so I put the character in the compound where it demonstrably carries that
  sense (区分, 心理学, 互市). A reviewer may consider that a cheat.
- **斯 as "this"** got the Mode-A anchor "Matches the common English definition for this."
  under the rule-11 exception (all senses formal). It is classical-only; a learner could be
  misled into using it.
- **中中 / 大心 / 大生 / 国中** are region-specific (Hong Kong / Taiwan). Registers were scored
  low, but the sentences present them as ordinary vocabulary.
- **中国人大** — native usage is overwhelmingly 全国人大; the headword forced the odd form into
  all three example sentences.
- The `一头` adverbial split (manner vs all-at-once) is a judgement call, already flagged.
